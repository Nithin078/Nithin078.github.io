DemoGen pipeline (visual walkthrough)

End-to-end flow from prompt → plan → record → narrate → compose. Run locally with Docker or Python 3.12+.

Text Prompt │ ▼ ┌──────────────┐ │ DOM Fetch │ Extract interactable elements from target page └──────┬───────┘ │ ▼ ┌──────────────┐ │ LLM Planner │ OpenRouter / Gemini → structured browser steps └──────┬───────┘ │ ▼ ┌──────────────┐ │ TTS Engine │ gTTS / ElevenLabs narration per step └──────┬───────┘ │ ▼ ┌──────────────┐ │ Automation │ Playwright/Selenium + screen capture └──────┬───────┘ │ ▼ ┌──────────────┐ │ Composer │ FFmpeg merges video + audio → MP4 └──────┬───────┘ │ ▼ Demo video output

Quick start: git clone https://github.com/Nithin078/DemoGen && docker build -t demogen . — see README for API keys and local UI.
